**产品定位**：官方公开日历 / RSS / 官方 API 元数据的**监控提醒软件订阅**；用户自行官网下单；不代订、不转售、不囤票。

## 我们收集什么

| 数据 | 用途 | 是否必填 |
|---|---|---|
| 邮箱 | 开通确认、提醒推送、退款与支持往来 | 是 |
| Telegram（@ 或 chat id） | 可选推送通道 | 否 |
| 监控站点（白名单内）与目标描述 | 创建提醒任务 | 是 |
| 套餐选择、支付成功状态（来自收款平台 webhook） | 履约与对账 | 支付后 |
| 浏览器本地草案（localStorage，部署前） | 仅本机草稿，不上传 | 可选 |

我们**不**收集：护照/证件号、支付卡完整号码（由 Creem 等 MoR 处理）、官网账号密码。

## 我们如何使用

- 仅用于提供与改进本提醒软件服务；
- 不会出售你的个人数据；
- 不会用你的身份代你登录第三方预约站。

## 共享

- **收款平台**（拟：Creem）：为完成支付与税务合规所需的最少信息（邮箱、订单金额等）。
- **推送通道**：若你填写 Telegram，提醒内容经 Telegram 送达。
- **法律要求**：仅在适用法律强制时披露。

## 保存与删除

- 活跃订阅期间保留任务与联系方式；取消后默认 **90 天内**删除或匿名化，除非法律要求更长。
- 申请删除：发邮件至 support 邮箱（见页脚 / `creem_onboarding_checklist.md` 建议：`poplxusa99+slot@…`），我们在合理期限内处理。

提醒发出即视为软件履约完成。**提醒 ≠ 抢到名额 / 订到票**；官网售罄、抽签未中、网络延迟导致错过，不退款（因我方漏发已公开公告的除外，见服务条款）。

政策重大变更将在本页更新日期并尽量邮件通知。继续使用即表示知悉更新后的政策。
