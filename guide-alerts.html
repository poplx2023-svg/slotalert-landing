官方 Availability Alerts — 中文配置指南

白名单源③可交付内容 · 2026-10-24（Asia/Shanghai）· 可离线静态打开

产品边界：本页教你自己在官网设置最多 3 条官方铃铛。 空位通知仍由官方发给你。我们不扫描 Recreation.gov 实时空位 /api，不代订、不转售。 提醒 ≠ 订到。
30 秒结论：登录 recreation.gov → 打开营地页 → Filters → View Results → 点铃铛 → 选日期/晚数 → Save Alert。 一账号 ≤3 条；收到邮件后立刻自己下单。季节首次放号不会走这条铃铛。

官方依据 证据 A

  • KB0011970 Camping Availability Alerts（最多 3 条；不保证订到；非季节首放）
  • Tips for Making Campsite Reservations（Tip #5）
  • robots.txt：Disallow /api

逐步：添加一条 Alert

  1. 打开目标营地页。
  2. 点 Filters，勾选真实需要的条件（帐篷/宠物/水电等）。
  3. 点 View Results。
  4. 点 铃铛（Bell）图标。
  5. 选 Start Date 与 Number of Nights；日期可灵活则勾选 Flexible ±3 days。
  6. 核对后点 Save Alert，看到绿色成功提示。

管理 / 删除

  1. 登录 → 菜单 → Account → Availability Alerts。
  2. 铅笔编辑部分细节；X 删除。
  3. 筛选条件不能事后改——要改 Filters 只能删了重建。满 3 条必须先腾槽。

必须知道的限制 证据 A

  • 同时最多 3 条活跃 Alerts。
  • 不能指定某一个营位号，只能营地 + 筛选。
  • 不会在季节开放/首次放号时通知；只在已有预约被释放（如取消）时通知。
  • 暂无短信 SMS。
  • 同一条件会发给所有设了相同 Alerts 的人 → 必须自己立刻下单。

多公园清单怎么排（≤3）

按「不可替代性」占槽，不要把三个「随便看看」塞满。已订到或行程取消 → 马上删，腾给下一目标。
#优先级放什么不建议
槽1P0唯一必去、靠取消才能上车的核心营地（日期已定）随便看看
槽2P1同行程备选营地（邻近）与槽1完全同质却各占一条
槽3P2第二行程窗口，或日期 ±3 天灵活的一条指望铃铛通知季节首放（不会来）

工作表可自建：公园 / 营地 / 日期 / 晚数 / Filters / 占用槽 / 备注。完整 Markdown 版见仓库 guides/official_alerts_zh.md。

收到邮件之后

  1. 点邮件里的 View and Book Campsite。
  2. 立刻自己完成支付；若已订走，换日期或换备选——这是正常竞争。
  3. 邮件可能显示大约多少人收到同一条（热门营地竞争激烈）。
